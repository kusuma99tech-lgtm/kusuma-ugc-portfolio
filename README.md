# Kusuma UGC Creator Portfolio

Responsive React + Vite website starter in a soft-luxury ivory, beige and muted-rose style.

## Run it in VS Code
1. Install Node.js LTS from https://nodejs.org/.
2. Open this folder in VS Code.
3. Choose Terminal > New Terminal.
4. Run `npm install`.
5. Run `npm run dev` and open the localhost URL shown.

## Add your own photos
Place these files in `public/images/`:
- `kusuma-hero.jpg` — homepage photo
- `kusuma-profile.jpg` — about-section photo

The gallery entries are in `src/data/portfolio.js`. Replace sample image URLs with your own content and update the title/category/description. Current gallery images are concept placeholders, not completed client campaigns.

## Build for Netlify
Run `npm run build`. Upload the generated `dist` folder to Netlify Drop, or connect this folder to a Git repository and deploy it. The contact form opens the visitor's email app; it does not store submissions on a server.
